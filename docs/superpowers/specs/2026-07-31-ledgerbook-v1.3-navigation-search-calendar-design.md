# LedgerBook Lite V1.3 导航、搜索与日历设计

## 1. 目标

在不迁移技术栈、不破坏 V1.2 本地账本数据和固定侧载签名的前提下，升级应用的全局导航与账单查找能力：

- 标题栏左侧显示当前账本，并从左侧打开账本抽屉。
- 标题栏中间提供文字搜索。
- 标题栏右侧从右侧打开可筛选的账单抽屉。
- 底栏保持四项，调整为“首页｜日历｜账户｜统计”。
- 四个主页面右下角固定显示圆形“＋”快速记账按钮。

“我的”不在 V1.3 范围内。

## 2. 方案比较

### 方案 A：继续把所有能力堆进单一 Activity

优点是改动表面最少。缺点是现有 Activity 已同时承担页面、弹窗、数据查询和导航职责，继续扩展会使搜索、抽屉、筛选和日历状态互相耦合，后续修复风险高。

### 方案 B：保留原生 Java View 与 SQLite，重构应用外壳和查询层（采用）

新增独立的标题栏、左右抽屉、搜索、筛选、日历和全局悬浮按钮组件；业务数据继续使用现有 `LedgerDb`。该方案兼顾交付速度、可测试性和升级兼容性。

### 方案 C：迁移到 Fragment、Navigation 或 Compose

长期结构更现代，但会显著扩大改动范围，增加样式回归、数据兼容和构建依赖风险。V1.3 不采用。

## 3. 全局应用外壳

### 3.1 层级结构

根布局使用 `FrameLayout`，从下到上包含：

1. 主内容层：标题栏、当前页面内容、底部导航。
2. 全局快速记账按钮。
3. 半透明遮罩层。
4. 左账本抽屉或右账单抽屉。
5. 对话框和输入组件。

左右抽屉互斥；打开一个抽屉前必须关闭另一个。点击遮罩、按返回键或向边缘方向滑动可关闭抽屉。

### 3.2 系统栏适配

继续读取真实 `WindowInsets`：标题栏增加状态栏安全区，底部导航增加手势导航安全区。悬浮按钮基于底栏实际高度定位，不使用固定屏幕坐标。

### 3.3 视觉与动效

沿用奶油黄、蜜桃粉、天空蓝和牛油果绿主题。抽屉使用 180–220ms 平移动画，遮罩同步淡入淡出。低端设备上不使用模糊和复杂阴影。

## 4. 标题栏

标题栏高度为 56dp，不含状态栏 inset。使用覆盖式布局保证搜索图标在屏幕几何中心，不因账本名称长短偏移。

### 4.1 左侧：当前账本

显示：

- 账本图标。
- 当前账本名称，超长时单行省略。
- 下拉箭头。

点击打开左侧账本抽屉。

### 4.2 中间：搜索

显示带无障碍描述的放大镜图标。点击打开全屏搜索面板。

### 4.3 右侧：账单

显示账单图标。点击打开右侧账单抽屉。若存在有效筛选条件，图标右上角显示小圆点。

## 5. 左侧账本抽屉

宽度为屏幕宽度的 84%，最大 340dp。

### 5.1 顶部

显示应用名称和“我的账本”。当前账本以奶油黄卡片高亮，并标记“当前”。

### 5.2 账本列表

列出所有账本：

- 账本名称。
- 本位币。
- 当前月收入、支出简要信息。

点击账本后立即切换全局账本，刷新首页、日历、账户和统计，再关闭抽屉。

### 5.3 底部固定操作

底部固定“账本管理”入口。账本管理支持：

- 新建账本。
- 重命名账本。
- 切换当前账本。
- 删除账本。

删除规则：

- 不允许删除最后一个账本。
- 删除前显示该账本的账户数和账单数。
- 必须二次确认。
- 删除后同时删除所属账户和账单，并自动切换到剩余账本。
- V1.3 不允许修改已有账本的本位币，避免历史金额语义变化。

## 6. 全屏文字搜索

### 6.1 搜索范围

默认搜索当前账本。顶部提供范围切换：

- 当前账本。
- 全部账本。

范围选择在本次打开期间保留，重新打开时恢复默认“当前账本”。

### 6.2 可搜索字段

文字搜索覆盖：

- 分类名称。
- 备注。
- 标签。
- 记账人。
- 转出或普通账户名称。
- 转入账户名称。

全部账本范围下同时匹配账本名称。

### 6.3 搜索行为

- 输入至少 1 个非空白字符后开始搜索。
- 输入停止 300ms 后执行查询，避免每次按键都重绘。
- 使用大小写不敏感的包含匹配。
- `%`、`_` 和转义字符按普通文字处理，防止 LIKE 通配符改变语义。
- 最多先显示 200 条，提供“继续加载”。
- 结果按发生时间倒序，并按日期分组。
- 全部账本模式下，每条记录额外显示账本名称。
- 点击结果打开账单详情对话框；长按仍可删除并恢复账户余额。

空查询显示搜索说明，不自动展示全部历史记录。无结果时显示可清除范围的空状态。

## 7. 右侧账单抽屉

宽度为屏幕宽度的 94%，最大 520dp，主要承载完整账单时间线。

### 7.1 顶栏

顶栏左侧显示标题和关闭按钮，右侧显示“详细分类”筛选按钮。下方第一行放置两个筛选入口：

- 时间。
- 账本。

### 7.2 时间筛选

采用已确认的推荐选项：

- 本月（默认）。
- 上月。
- 本年。
- 自定义日期范围。

自定义范围使用开始日期和结束日期选择器；结束日期不得早于开始日期。日期边界按手机本地时区的自然日计算。

### 7.3 账本筛选

默认当前账本，可选择：

- 当前账本。
- 全部账本。
- 某个具体账本。

当主界面切换账本时，若账单抽屉仍处于“当前账本”，筛选范围跟随切换；若用户已选择具体账本或全部账本，则保持原筛选。

### 7.4 详细分类筛选

点击右上角筛选按钮打开分类面板，支持：

- 账单类型：全部、支出、收入、转账。
- 具体分类：根据所选类型动态列出带图标分类。
- 账户：全部或某一账户。
- 记账人：全部或某一记账人。

默认均为“全部”。支持“一键清除”。V1.3 不加入金额区间、标签组合和报销状态等高级条件，避免筛选面板过度复杂。

### 7.5 账单列表

- 按日期分组，组头展示当日收入和支出合计。
- 每条记录展示图标、分类、账户、时间、金额；跨账本时显示账本名称。
- 点击打开详情。
- 长按删除并恢复余额。
- 筛选无结果时显示当前筛选摘要和清除按钮。

## 8. 底部导航

V1.3 保持四项：

1. 首页。
2. 日历。
3. 账户。
4. 统计。

原“账单”底栏入口移除，完整账单列表由右侧账单抽屉承载。

切换底栏页面时保留各页面的轻量状态：日历月份、账户滚动位置和统计月份。应用重启后只要求恢复当前账本，不要求恢复页面滚动位置。

## 9. 日历页面

### 9.1 月份导航

顶部显示“上一月｜YYYY 年 M 月｜回到今天｜下一月”。同时支持左右滑动切换月份。

星期顺序按本地常用布局显示为周一至周日。月份网格固定为 6 行，邻月日期使用弱化颜色。

### 9.2 每日格子

采用已确认的推荐展示：

- 显示日期数字。
- 有账单时显示当天支出总额，金额过长时紧凑缩写。
- 当天存在收入时显示绿色小圆点。
- 今天使用描边强调。
- 当前选中日期使用柔和底色。

支出为零但存在转账时，显示蓝色小点，避免误认为当天完全没有记录。

### 9.3 点击某日

点击日期后，在日历下方展开该日账单列表，不跳离日历页面：

- 标题显示完整日期和当日收支合计。
- 列出该日全部账单。
- 点击账单查看详情。
- 长按删除。
- 无账单时显示“这天还没有记录”和“记一笔”入口。

点击邻月日期时先切换到对应月份，再选中该日。

## 10. 全局快速记账按钮

在首页、日历、账户和统计四个页面中，右下角固定显示圆形“＋”按钮：

- 位置在底栏上方 16dp、屏幕右侧 16dp。
- 直径 58dp，使用蜜桃粉或奶油黄主色。
- 点击直接打开现有 V1.2 记账表单。
- 日历选中某日时，从日历页点击“＋”默认使用该日和当前时间；其他页面默认使用当前时间。
- 打开抽屉或模态对话框时，抽屉/对话框位于按钮之上；关闭后按钮仍保持原位。
- 提供明确的无障碍描述“快速记账”。

## 11. 账单详情

搜索、右侧账单抽屉和日历日列表共用同一个详情对话框，展示：

- 类型、分类和金额。
- 账本。
- 账户或转账账户。
- 时间。
- 记账人。
- 标签、备注、优惠、报销和预算状态。

V1.3 详情页只提供关闭和删除，不加入编辑账单；编辑功能单独进入后续版本。

## 12. 数据与查询层

不修改现有表结构，不提高数据库版本。新增查询和管理方法：

- `searchTransactions(scope, query, offset, limit)`。
- `getFilteredTransactions(filter, offset, limit)`。
- `getTransactionsForDay(ledgerId, dayStart, dayEnd)`。
- `getMonthDaySummaries(ledgerId, monthStart, monthEnd)`。
- `getLedgerCounts(ledgerId)`。
- `renameLedger(ledgerId, name)`。
- `deleteLedger(ledgerId)`。

查询统一返回包含账本名称的展示模型，避免页面重复查询。搜索和筛选参数使用绑定变量，不拼接用户输入。

当前账本 ID 使用 `SharedPreferences` 持久化；若该账本被删除或不存在，则回退到第一个账本。

## 13. 组件边界

建议新增以下独立组件：

- `LedgerV13Activity`：只负责外壳和全局状态协调。
- `LedgerDrawerView`：左侧账本抽屉。
- `BillDrawerView`：右侧账单抽屉。
- `TransactionSearchDialog`：全屏搜索。
- `CalendarPageView`：月份日历和每日账单。
- `TransactionDetailDialog`：统一账单详情。
- `TransactionFilter`：不可变筛选条件模型。
- `TransactionQueryRules`：日期范围、范围切换和搜索转义规则。

现有金额键盘、分类选择、账户选择、时间滚轮和记账人选择继续复用。

## 14. 错误处理与数据安全

- 查询失败时显示错误提示，不清空当前筛选状态。
- 账本切换后若原账户筛选不属于新账本，自动恢复“全部账户”。
- 自定义日期范围非法时禁止确认。
- 删除账本和账单均在数据库事务中执行。
- 删除当前账本成功后必须立即选择有效账本再刷新界面。
- 搜索和筛选结果为空不视为错误。

## 15. 测试与验收

### 15.1 单元测试

覆盖：

- 搜索特殊字符转义。
- 当前账本与全部账本范围。
- 本月、上月、本年和自定义日期边界。
- 闰年、跨月和本地自然日边界。
- 分类、账户和记账人组合筛选。
- 日历每日支出合计及收入/转账标记。
- 账本删除保护规则。

### 15.2 构建门禁

CI 必须依次通过：

1. 全部单元测试。
2. Android Java 编译。
3. Debug APK 组装。
4. APK v2 签名验证。
5. SHA-256 生成和产物上传。

### 15.3 手工验收路径

- 状态栏、底栏和悬浮按钮在刘海屏与手势导航下不重叠。
- 左右抽屉方向、遮罩和返回键行为正确。
- 搜索当前账本与全部账本结果正确。
- 时间、账本、类型、分类、账户和记账人筛选组合正确。
- 日历每日金额与实际账单一致。
- 从四个页面点击“＋”均可保存账单并刷新相关页面。
- V1.2 覆盖安装后原账本、账户和账单仍存在。

## 16. 版本与范围边界

版本升级为 `1.3.0` / versionCode 4，继续使用 V1.1 起的固定签名，可直接覆盖安装 V1.2。

V1.3 明确不包含：

- “我的”页面。
- 云同步、登录和共享账本。
- 账单编辑。
- 高级金额区间和复杂标签筛选。
- 修改已有账本本位币。

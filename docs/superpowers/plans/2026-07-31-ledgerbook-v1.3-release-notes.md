# LedgerBook Lite V1.3.0 Release Notes

## Navigation

- Header-left current ledger button opens a left ledger drawer.
- Header-center search supports current-ledger and all-ledger scopes.
- Header-right bill button opens a filtered right bill drawer.
- Bottom navigation is Home, Calendar, Accounts, and Statistics.
- A circular quick-entry button remains visible above the bottom navigation.

## Ledger and bill management

- Create, switch, rename, and delete ledgers.
- Ledger deletion requires two confirmations and is blocked for the final ledger.
- Bill filters include time, ledger, type, category, account, and bookkeeper.
- Search covers category, note, tags, bookkeeper, accounts, and ledger name in all-ledger mode.

## Calendar

- Monday-first 42-cell month grid.
- Daily expense totals.
- Green income marker and blue transfer marker.
- Selected-day bill list with detail and delete actions.

## Compatibility

- Database schema remains unchanged from V1.2.
- Fixed signing certificate remains unchanged.
- V1.2 can be upgraded in place without clearing local data.

# V1.5 Progressive Finance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a progressive finance system that keeps fast daily bookkeeping simple while adding optional advanced modules.

**Architecture:** Extend the existing SQLite model with versioned migrations. Keep modules isolated behind enable flags and preferences. Preserve V1.4.1 data compatibility.

**Tech Stack:** Android Java, SQLite, existing custom UI components, JUnit tests, Gradle APK build.

## Global Constraints

- Preserve existing ledgers, accounts, balances and transactions.
- Keep local-first storage; no mandatory account login or cloud sync.
- Advanced modules must be independently enabled.
- Any operation affecting balances requires explicit confirmation.
